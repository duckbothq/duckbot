# Security Policy

Do not report vulnerabilities in a public issue or discussion.

Use GitHub private vulnerability reporting at
`https://github.com/duckbothq/duckbot/security/advisories/new`, or email
`info@igears.net` with “Duckbot security” in the subject. Include reproducible steps and
the likely impact; never include real customer personal data.

High-priority reports include privacy-gateway bypasses, placeholder-map exposure,
approval-gate bypasses, prompt injection that promotes retrieved content to instruction,
credential/log leakage, connector scope escapes, and audit-chain tampering.

During pre-release development, only the latest `main` revision is supported.
