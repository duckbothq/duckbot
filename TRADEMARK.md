## Why

The code is permissively licensed precisely so that nobody has to ask us for permission to use it. The name exists so that people can tell which builds come from this project. Keeping the two separate is what lets us give the code away.

This is the same arrangement used by many open-source projects, and it is not intended to restrict genuine use of the software.
