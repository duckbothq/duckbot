# Support

## Community edition — free, as-is

The Duckbot community edition is provided free of charge and **as-is**, with community support only.

**Use [Discussions](https://github.com/duckbothq/duckbot/discussions) for:**

- How do I do X?
- It will not install on my machine
- Which model should I use?
- Does it work with my system?
- Ideas, suggestions, and showing what you built

**Use [Issues](https://github.com/duckbothq/duckbot/issues) only for:**

- A reproducible bug, with steps to reproduce
- A specific feature request

Issues that are questions will be converted to Discussions. This is not unfriendliness — it keeps the issue tracker usable for actual defects, which is what makes the software better for everyone.

There is no private support channel for the community edition. Please do not email or message maintainers directly for support; those requests cannot be answered.
